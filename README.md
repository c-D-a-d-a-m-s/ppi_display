# Radar Display #

Gathers data from a rotating radar sensor on an STM32 Nucleo Board and displays said data in a window on a Linux machine.

## Built With ##

STM32 Nucleo Board (Model: TBD)
SDL3

## Purpose ##
Through this project, I intend to gain a better understanding of
Linux kernel- and user-space, Linux device drivers, Cortex M processors,
and radar DSP techniques.
